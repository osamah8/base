# Sources

Originals that evidence the project's source of truth. Files arrive in `inbox/`, are filed here once their facts are recorded, and are never edited or deleted.

## Structure

`sources/<category>/<year>/<Title>.<ext>`

- **Category**: what kind of evidence it is (table below).
- **Year**: the year the thing happened, not the year the document was issued.
- **Title**: plain description, no date (the folder gives the year). Add ` - <document type>` when one event has several documents.

Each category folder has a `README.md` indexing every file in it by year.
